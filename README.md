# 🚗 台灣駕訓班 S 型彎道（曲線進退）擬真模擬器

專為駕訓班學員打造的 Web 擬真訓練工具。利用手機作為無線方向盤，搭配電腦大螢幕 3D 第一人稱駕駛座、雙側照後鏡與鳥瞰地圖，練習 S 型彎轉方向盤圈數與看點肌肉記憶。

---

## 🌟 核心特色
1. **雙裝置無線聯動 (免裝 App)**：
   - 電腦開啟大螢幕顯示 3D 駕駛視角與照後鏡。
   - 手機掃描 QR Code 即刻化身方向盤（利用 WebRTC 點對點連線，低延遲且完全免費）。
2. **擬真 1.5 圈（540 度）方向盤**：
   - 支援雙手握持手機連續打滿一圈半（540°），練習換手手感與回正記憶。
   - 手機螢幕支援觸控手動轉盤備用。
3. **台灣駕訓班正統看點（教練核心口訣）**：
   - **車頭蓋與雨刷噴水孔**：對齊車道中心與弧線。
   - **雙側照後鏡**：清楚顯示**「前門把手與白線/黑管的距離」**（保持約 1 拳寬度）。
4. **真實壓線警報**：
   - 只要四個輪胎任一壓到感應黑管，立即響起電子蜂鳴器（扣 32 分），手機同步震動。
5. **怠速與檔位控制**：
   - 自動以駕訓班微速（約 4 km/h）怠速滑行。
   - 手機提供大面積煞車踏板（按住煞停）與 D/R 檔位切換。

## 🖥️ 本地啟動預覽 (2 種方法)

### 方法一：使用 VS Code Live Server 擴充套件（最簡單）
1. 在 Antigravity 或 VS Code 中，於 `index.html` 按右鍵。
2. 點擊 **「Open with Live Server」**。
3. 瀏覽器便會自動開啟模擬器！

### 方法二：使用 Python 或 Node.js 終端機
在 `S_trainer` 目錄下執行以下任一指令：
```bash
# Python (若有安裝 Python)
python -m http.server 8000

# 或 Node.js
npx serve
```
接著在瀏覽器打開 `http://localhost:8000` 即可。

## 📱 手機連線與免費雲端發布 (GitHub Pages)

由於現代智慧型手機（iOS / Android）的陀螺儀感應器要求在 **HTTPS** 安全環境下運作，最推薦且**100% 免費**的方法是發布至 **GitHub Pages**：

1. 到 [GitHub.com](https://github.com) 建立一個免費的公開倉庫（例如名為 `S_trainer`）。
2. 將本資料夾的所有檔案上傳或 push 至該倉庫。
3. 點選倉庫的 **Settings** ➜ **Pages** ➜ **Branch** 選擇 `main` 並按 Save。
4. 稍等約 1 分鐘，GitHub 會給你一個專屬的 HTTPS 網址（例如 `https://yourname.github.io/S_trainer/`）。
5. 用電腦開啟該網址，拿出手機相機掃描螢幕上的 QR Code，即可開始練習！

## 🎮 電腦端鍵盤快捷鍵 (本機免手機測試用)
| 按鍵 | 功能 |
| :--- | :--- |
| `←` / `A` | 方向盤向左轉 (最高打滿 1.5 圈) |
| `→` / `D` | 方向盤向右轉 (最高打滿 1.5 圈) |
| `C` | 方向盤一鍵回正 (0°) |
| `空白鍵 (Space)` | 踩下煞車 (按住煞停) |
| `W` | 切換為 D 檔 (前進) |
| `S` | 切換為 R 檔 (倒車) |
| `R` | 重置車輛回到起點 |

## 💡 教練 S 彎進退秘笈提醒
1. **前進進 S 彎**：
   - 車頭蓋中心對準車道中央慢慢進入。
   - 進入第一彎時，注意看**左照後鏡**，讓**前門手把**與彎道黑管維持約 1 個拳頭（15~20cm）距離；太近回半圈，太遠加轉。
   - 看到車身即將拉直進入第二彎交界時，將方向盤迅速回正 1.5 圈向前慢滑。
   - 進入第二彎時，改看**右照後鏡**，維持**右前門手把**與黑管距離。
2. **倒車出 S 彎**：
   - 換 R 檔，原路慢速倒退，同樣透過後照鏡觀察門把與邊線間距調整方向盤。
